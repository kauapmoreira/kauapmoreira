## 🧠 Sobre Mim

Comecei minha jornada na programação pelo **hardware**, usando **C++ em Arduino** para aplicar lógica de programação em circuitos e sensores reais. Atualmente sou estudante no SENAI-SP (Técnico em Desenvolvimento de Sistemas) e estou evoluindo para me tornar um Desenvolvedor Full Stack.

- 📍 **Local:** São Caetano do Sul, SP
- 🎯 **Foco atual:** Lógica com C++, Redes, Banco de Dados e Web.
- 💼 **Buscando:** Estágio ou primeira oportunidade na área de tecnologia.
